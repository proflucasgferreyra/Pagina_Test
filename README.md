# 📘 Pagina_Test

## 🧪 Descripción

Este repositorio contiene un **proyecto de prueba (demo educativo)** desarrollado para estudiantes que están comenzando en programación web.

El objetivo es demostrar una **conexión básica a una base de datos MySQL usando PHP**, junto con una estructura simple de frontend.

> ⚠️ Este proyecto es únicamente con fines educativos y de prueba (no productivo).

---

## 🛠️ Tecnologías utilizadas

* **PHP** → Backend (conexión a MySQL)
* **MySQL** → Base de datos (script incluido)
* **JavaScript** → Interacciones básicas
* **CSS** → Estilos
* **HTML** → Estructura (dentro de PHP)

---

## 🗂️ Estructura del proyecto

```
Pagina_Test/
 ├── test.php        # Script principal (conexión a DB)
 ├── script.js       # Lógica cliente
 ├── estilo.css      # Estilos
 └── dbTest.sql      # Script de base de datos
```

---

## ⚙️ Requisitos

* Servidor local (XAMPP, WAMP, etc.)
* PHP 7+
* MySQL

---

## 🧪 Cómo usar el proyecto

1. Importar la base de datos:

```
dbTest.sql
```

2. Configurar credenciales en:

```
test.php
```

3. Ejecutar en servidor local:

```
http://localhost/Pagina_Test/test.php
```
